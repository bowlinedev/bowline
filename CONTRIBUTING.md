# Contributing

## Developer Certificate of Origin

Every commit must be signed off, which certifies the terms at https://developercertificate.org/:

    git commit -s

Pull requests with unsigned commits fail CI.

## Toolchain

- Go 1.26 or later to build the CLI and run the workspace; the runtime module itself supports Go 1.24
- pnpm 10 or later
- staticcheck: `go install honnef.co/go/tools/cmd/staticcheck@latest`

## Checks before pushing

    gofmt -l . && go vet ./... && staticcheck ./... && go test ./...
    cd cmd/bowline && go vet ./... && go test ./...
    pnpm install && pnpm check && pnpm test

## Golden files

Files under `spec/` are generated by tests. Regenerate with `go test ./contract -update` and commit the result.
