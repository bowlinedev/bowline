# bowline-client

Runtime for Python clients generated by `bowline gen` with the `python` target: the transport, the error model, and the helper types the generated module imports. It depends on `httpx` and Pydantic 2 and nothing else.

```python
from bowline_client import BowlineError, SyncTransport

from bowline import GetInvoiceInput, SyncClient

client = SyncClient(SyncTransport("http://localhost:8080/api"))
try:
    invoice = client.invoices.get(GetInvoiceInput(id=3))
except BowlineError as err:
    print(err.code, err.message, err.issues)
```

`Transport` is the asynchronous twin over `httpx.AsyncClient`; both offer `call`, `subscribe` for server-sent event subscriptions, and `upload` for multipart uploads. Inputs are validated by Pydantic before a request leaves the process and outputs are validated as they arrive, so a mismatch between the contract and the server is a typed error, never a silent `None`.
