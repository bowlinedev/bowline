# bowline_client

Runtime for Elixir clients generated by [Bowline](https://github.com/bowlinedev/bowline). Generated modules carry the types, decoding, validation, and procedure wrappers; this package carries the transport, the error envelope, and the helpers those modules call.

```elixir
transport = BowlineClient.Transport.new(base_url: "http://localhost:8080/api")

case Ledger.Invoices.get(transport, %Ledger.Types.GetInvoiceInput{id: 3}) do
  {:ok, %Ledger.Types.Invoice{} = invoice} -> invoice.total
  {:error, %BowlineClient.Error{code: :not_found}} -> nil
end
```

`BowlineClient.Transport.new/1` takes `base_url`, optional `headers` (a map or a zero-arity function evaluated per call), and `req` options for the underlying `Req` client. Every call returns `{:ok, value}` or `{:error, %BowlineClient.Error{}}` with the server's code as an atom, the HTTP status, and validation `issues`. Subscriptions return `{:ok, stream}` over server-sent events, and uploads send the input and the file as one multipart body.

Generate a client with `bowline gen` and an `elixir` target in `bowline.json`:

```json
{ "targets": { "elixir": { "out": "elixir/lib/bowline.ex", "package": "Ledger" } } }
```
