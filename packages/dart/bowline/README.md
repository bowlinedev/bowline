# bowline

Runtime for Dart clients generated by [Bowline](https://github.com/bowlinedev/bowline) from a Go API contract. The generated `bowline.dart` carries the types, their `fromJson`, `toJson`, and `validate()` methods, and one client class per router node; this package carries the transport, the error model, and the decoding helpers the generated file calls.

```dart
import 'package:bowline/bowline.dart';
import 'bowline.dart' as api;

final client = api.Client(Transport(baseUrl: Uri.parse('http://localhost:8080/api')));
final page = await client.invoices.list(api.ListInvoicesInput(limit: 20));
try {
  await client.invoices.create(api.CreateInvoiceInput(customerId: 1, lines: []));
} on BowlineException catch (e) {
  print('${e.code.wire}: ${e.issues}');
}
```

`Transport.call` sends queries as `GET` with the input in the `input` query parameter and mutations as `POST` with a JSON body, merges static headers with per-call `CallOptions.headers`, and maps the server's error envelope to `BowlineException` with the same sixteen codes the Go runtime uses. Network failures are `Code.unavailable`, timeouts are `Code.deadlineExceeded`, and inputs are validated locally before a request leaves. `subscribe` streams server-sent events and `upload` sends a two-part multipart body.
